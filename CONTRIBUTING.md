# Como contribuir

Consulte o [README](README.md) e o [guia local](docs/LOCAL_DEVELOPMENT.md).

1. Crie uma branch para uma alteração com escopo claro.
2. Preserve a autorização por titular e o consentimento nas rotas de saúde.
3. Use apenas dados sintéticos em testes, exemplos e capturas de tela.
4. Execute `.\scripts\test.ps1` e atualize a documentação afetada.
5. Abra um pull request explicando o problema, a mudança e a validação.

Nunca inclua credenciais, arquivos `.env`, dumps ou dados pessoais. Preserve migrations aplicadas; mudanças de schema devem receber uma nova migration.
